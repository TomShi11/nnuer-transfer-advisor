## 1. 项目概览与设计理念

在传统观念中，“生化环材”常被贴上天坑标签，许多大一同学面对繁重的化学实验和传统就业预期产生焦虑。
然而，在**南京师范大学（仙林校区）**，学校推行**“转出不设门槛（不卡转出比例）、转入择优选拔”**的开明政策。转专业是一次主动掌握人生方向舵的机会，但绝不是“非赢即输”的单行道。

本系统采用**现代化零依赖单页应用（SPA）**架构：
- **纯静态单文件**：内置 Vue 3 + Tailwind CSS + Canvas Confetti，双击 `index.html` 即可在任何浏览器流畅运行；
- **真实南师数据**：全面对标南师大教务处（菁林网）历年转专业考核办法、学分置换规则与仙林校区各学院特点；
- **全闭环辅助**：从“心理赋能 → 政策拆解 → 赛道匹配 → 申请材料生成 → 面试模拟 → 补修学分测算 → 长期规划”，一站式解决全部痛点。

## 3. 核心功能板块详解

### 模块 1：现状自我诊断与心声体检 (Diagnosis Hub)
- **多维评估模型**：从“大一加权绩点预估”、“数理与代码接受度”、“对化学实验的耐受度”、“核心职业追求（体制/IT/经管/空间）”及“补修学分承压能力”5 个维度量化测评。
- **动态量化输出**：
  - **转出迫切度指数（0~100）**：精准洞察转轨内心动力；
  - **转入胜算底气指数（0~100）**：评估当前绩点与数理潜力的综合竞争力；
  - **大二补课抗压承载力（0~100）**：科学预测平级补修学分的心理与精力承载阈值；
  - **定制诊断锦囊**：根据选项实时生成专属评语。

### 模块 2：南师大转专业全景作战地图 (NNU Roadmap)
- **五大作战阶段时间线**：
  1. **期末筑基期（大一上，12月-1月）**：守住高数、思政、英语加权成绩，严守“零挂科”铁律；
  2. **蓄力预演期（大一寒假，1月-2月）**：提前自学目标专业核心先修课，打磨自荐信初稿；
  3. **政策侦察期（大一下开学~4月）**：紧盯菁林网（`jwc.njnu.edu.cn`）通告，锁定目标接收学院细则与名额；
  4. **决战考核期（4月下旬~5月中旬）**：教务系统申报，沉着应战专业笔试与专家综合面试；
  5. **平稳交接期（6月~大二开学）**：公示录取，办理学分置换，制定大二平级补修课表。
- **高频政策 FAQ 问答卡片**：直击转出限制、平级升大二还是降级、学分置换认定、未被录取的安全保底等四大现实顾虑。

### 模块 3：转出目标专业雷达与匹配引擎 (Major Radar Matcher)
覆盖南师大仙林校区 5 大赛道与 10 个热门细分专业，根据测评结果动态加权排序：
1. **近亲王牌·高性价比**：
   - **地理科学学院 · 地理信息科学 (GIS)**：南师A类学科，空间信息与计算机结合，学分兼容度最高，考研/IT通吃；
   - **地理科学学院 · 遥感科学与技术**：空天影像、AI识别、环境遥感监测交叉，转入难度适中。
2. **高薪硬核·技术突围**：
   - **计算机与电子信息/AI学院 · 计算机科学与技术**：直通互联网与科技大厂后端，高数底子硬指标，补修压力 5 星；
   - **软件工程**：注重架构开发与工程应用；
   - **人工智能 (AI)**：前沿算法先锋，考查线性代数与逻辑思维。
3. **体制大户·文法底蕴**：
   - **法学院 · 法学**：文科王牌，法考与公务员招录大户，重思辨面试与文笔；工科逻辑在知识产权与环境法领域具备降维打击优势；
   - **文学院 · 汉语言文学**：百年底蕴，机关文秘与选调生黄金跳板。
4. **经管商业·复合多维**：
   - **商学院 · 金融学**：资本市场运作、商业分析，工科高数基础是加分项；
   - **商学院 · 数字经济**：现代经济学与 Python 大数据分析前沿交叉。
5. **名校传承·铁饭碗教育**：
   - **思想政治教育 / 汉语言文学（师范）**：南师立校之本，长三角公立中小学编制绿卡，稳定无忧。

### 模块 4：超凡四维立体人生规划沙盘 (Life Sandbox)
- **路径 A（最优线）**：成功转入第一志愿的大二融入、补课节奏与保研规划；

- **路径 D（大格局）**：20~30 岁长期主义成长心态，培养可迁移元能力，跳出单一本科学历局限。

### 模块 5：实操通关三合一工具箱 (Action Toolkit)
- **工具 A：自荐信 / 个人陈述（PS）智能生成器**：
  - 自动适配目标学院与专业名称；

- **工具 B：面试高频灵魂问答抽卡演练舱**：
  - 收录南师大考核专家最常抛出的 6 个核心难题（如“为什么想离开环工”、“环工学了一年是不是浪费了”、“补课压力大能抗住吗”、“读过什么专业经典”、“失败了怎么办”等）；

  - 动态计算通识等额冲抵学分、专业课转任选学分、大二平级需补修学分与每周建议排课压力（节/周）。

| **转出资格门槛** | 学院不卡转出比例，无名额上限；要求第一学年无严重违纪处分，必修课原则上无挂科 | 大一上期末考试守住底线，高数/英语力争80+，严防挂科 |
| **考核录取规则** | 综合成绩 = 原专业大一加权成绩(30%~50%) + 接收学院笔试/面试(50%~70%) | 面试前务必熟记自荐信核心逻辑，突出对目标专业的学科理解与诚意 |

| **未录取兜底** | 考核未通过者继续在原专业就读，不记入档案，完全不影响评奖评优与保研加权 | 卸下一切心理负担，大胆申报，没有任何后顾之忧 |

   - 毕业简历呈现为“环境工程 + 空间数据挖掘”，在智慧环保、数字化碳交易企业中比纯环工或纯码农更具稀缺性。

## 6. 快速启动与运行指南

本应用为纯静态现代单页应用，无需安装复杂的构建工具或后端环境。

### 方法一：Windows 批处理一键启动（最推荐）
直接双击运行目录下的：
```cmd
start.bat
```
系统将自动调用你的默认浏览器打开页面。

### 方法二：Windows PowerShell 预览脚本
在终端中进入当前目录运行：
```powershell
powershell -ExecutionPolicy Bypass -File preview.ps1
```
脚本将自动检测 Python 或 Node.js 启动本地 HTTP 服务，或直接在浏览器中打开。

### 方法三：浏览器直接打开
直接在资源管理器中双击 `index.html`，或用 Chrome、Edge、Safari 等现代浏览器打开即可。

## 7. 部署到 Vercel 与 Cloudflare 域名解析（nnu.11s.space）

### 7.1 一键部署脚本
在项目根目录已经内置了全自动化部署配置文件 `vercel.json` 及执行脚本：
- **Windows 双击执行**：直接运行 `transfer-advisor-web\deploy-vercel.bat`
- **PowerShell 执行**：
  ```powershell
  cd transfer-advisor-web
  powershell -ExecutionPolicy Bypass -File deploy-vercel.ps1
  ```

### 7.2 Cloudflare DNS 解析配置步骤
当 Vercel 部署完成后，请进入 Cloudflare 控制台进行 DNS 解析绑定：
1. 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)，选择域名 `11s.space`；
2. 点击左侧导航栏 **DNS** -> **记录 (Records)**；
3. 点击 **添加记录 (Add record)** 并填写以下配置：
   - **类型 (Type)**：`CNAME`
   - **名称 (Name)**：`nnu`
   - **目标 (Target)**：`cname.vercel-dns.com`
   - **代理状态 (Proxy status)**：**仅限 DNS (DNS only / 灰色小云朵)** *(重要：切勿开启橙色云朵，防止 SSL 证书颁发验证超时或重定向冲突)*
   - **TTL**：`自动 (Auto)`
4. 点击 **保存 (Save)**。通常 1~3 分钟内解析生效，即可通过 `https://nnu.11s.space` 访问！
